### Hello World App
A simple cross-platform desktop application built using Qt 6 (QML) and CMake. This application displays a simple card UI with personal profile information.

## 📸 Preview
Application UI: Displays personal greeting, current status (Student), employment background (Company), and location (Cairo).

## 🛠️ Prerequisites & System Requirements
Before building the project, ensure you have the following installed on your Linux system:

## 1. Build Tools & Compilers
```bash
sudo apt update && sudo apt install -y build-essential gcc g++ cmake ninja-build
```

## 2.OpenGL Development Libraries

```bash
sudo apt install -y libgl1-mesa-dev libgl-dev
```

## 3. Qt 6 Framework
Qt 6 (Qt 6.11.1 or compatible)

Qt Quick / Declarative modules
